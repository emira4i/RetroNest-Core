# Credits

The RetroNest core host is a thin layer: it loads emulator cores written by other people and gives
them a screen, sound and input on Android. The emulation itself is entirely the work of the projects
below. Thank you to everyone who wrote and maintains them.

## Libretro

The core host implements the frontend side of the [Libretro API](https://www.libretro.com/), created
and maintained by the Libretro / RetroArch team. The API header `libretro.h` (MIT license) is not
copied into this repository; the setup script downloads it from
[libretro/RetroArch](https://github.com/libretro/RetroArch).

not part of this repository.

## Test programs

The small test programs under `corehost/src/androidTest/assets/testroms` are generated by
`tools/testroms/make_test_roms.py`, written for this project. They contain no third-party code.

If a project is missing here or credited incorrectly, please open an issue.
